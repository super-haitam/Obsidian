## Design Pattern

> [!note] Definition: Design pattern
> It's a predefined template made by the "Gang of Four" to standardize and simplify the solution to commonly found problems.

## Code Smell

>[!note] Definition: Code Smell
>A surface-level characteristic in source code that indicates a deeper, more important structural or design problem.
>
>Importantly, it **is not a bug** - the code compiles, runs, and produces the correct output. However, it signals that the code may be poorly structured, difficult to maintain, rigid or prone to introducing bugs when modified in the future.
